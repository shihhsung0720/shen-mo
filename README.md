# 森SHEN 內容工作空間

森SHEN 品牌的內容策略、題材池、短影音腳本工作專案。
給接手的人 / AI：先讀 `CLAUDE.md`。

---

## 目錄怎麼看

| 資料夾 | 用途 | 變動頻率 |
|---|---|---|
| `01-brand/` | 品牌核心：定位、客群、語氣 | 很少 |
| `02-inventory/` | 過去貼文盤點 | 偶爾 |
| `03-axis-map/` | 內容軸地圖 | 季度 |
| `04-topics/` | 題材池 | 每週 |
| `05-scripts/` | 短影音腳本（按日期分檔） | 每天 |
| `06-prompts/` | 給 Claude 的標準範本 | 偶爾 |

## 兩條工作路線

- **路線 1**：盤點過去 → 找出現有內容軸 → 找空白 → 補新題
  - 起點：`02-inventory/` → `03-axis-map/` → `04-topics/`
- **路線 2**：直接產生新題材 → 排程 → 寫腳本
  - 起點：`04-topics/backlog.md` → `05-scripts/`

## 動之前必讀

1. `01-brand/voice.md` — 不能用的詞、紅線
2. `03-axis-map/taboo.md` — 不能碰的題
3. `06-prompts/` — 任何 AI 產出都先用這裡的範本
