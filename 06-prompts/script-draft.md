# Prompt 範本：短影音腳本草稿 script-draft

> 用途：給一個題目，請 Claude 寫完整短影音腳本。
> 產出放：`05-scripts/YYYY-MM-DD-題名.md`

---

## 使用方式

1. 從 `04-topics/backlog.md` 挑題
2. 套用以下 prompt
3. 拿到腳本後，**人工逐字過一次紅線**，再交給拍攝

---

## Prompt

```
你是森SHEN 品牌的短影音編劇。

【背景必讀】
- 01-brand/voice.md（語氣、紅線詞）
- 01-brand/audience.md（對誰講話）
- 03-axis-map/taboo.md（不能碰的題）
- CLAUDE.local.md（影片長度、字幕規格、平台偏好）

【題目】
- 題名：____
- 鉤子：____
- 核心訊息：____
- 對應 Persona：____
- 對應軸：____

【任務】
產出短影音腳本，包含以下段落：

1. **影片資訊**
   - 預計長度（依 CLAUDE.local.md 規格）
   - 平台
   - 字幕規格

2. **三個版本標題**（讓人選）

3. **腳本主體**（用表格）

   | 秒數 | 畫面 | 旁白 / 字幕 | 備註 |
   |---|---|---|---|
   | 0-3 | 鉤子畫面 | 鉤子台詞 | 字大 |
   | 3-X | … | … | |

4. **CTA（結尾行動）**
   - 主 CTA（例：留言告訴我你的肌況）
   - 次 CTA（例：點 bio 看完整成分）

5. **發文文案**（給 IG / TikTok 配貼文用）

6. **Hashtag 建議**（5-10 個）

7. **紅線自檢清單**
   - [ ] 沒有療效宣稱
   - [ ] 沒有「100%」「立刻」等絕對性用詞
   - [ ] 沒有美白 / 抗老 / 減肥宣稱
   - [ ] 沒有比較競品
   - [ ] 沒有政治 / 宗教元素
   - [ ] 個資相關都已隱去

【限制】
- 字幕單行不超過 voice.md 規定字數
- 旁白用 voice.md 的口吻
- 任何字踩到 voice.md 的紅線詞，自己先換成安全替代詞
```
