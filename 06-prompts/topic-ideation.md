# Prompt 範本：題材發想 topic-ideation

> 用途：給定一條軸（或一個季節 / 痛點），請 Claude 發想 N 個可拍的題目。
> 產出放：`04-topics/backlog.md`

---

## 使用方式

1. 決定發想的「種子」：軸 / 客群痛點 / 節氣 / 紅題複製
2. 把以下 prompt 套用、填入種子
3. 拿到題目清單，自己過一次紅線檢查再排進 backlog

---

## Prompt

```
你是森SHEN 品牌的內容企劃。

【背景必讀】
- 01-brand/positioning.md
- 01-brand/audience.md
- 01-brand/voice.md
- 03-axis-map/taboo.md（紅線，絕對不能踩）

【種子】
（在這裡填入其中一個或多個）
- 軸：____（例：成分知識）
- 客群痛點：____（例：換季肌膚敏感）
- 節氣 / 時事：____（例：立秋）
- 想複製的紅題：____（貼連結或描述）

【任務】
產出 10 個短影音題目，每個題目包含：

1. **題名**（短、有鉤子，10 字內）
2. **前 3 秒鉤子**（觀眾為什麼不滑掉）
3. **核心訊息**（一句話）
4. **對應軸**（current-axes 或 extended-axes 的哪一條）
5. **對應 Persona**（A / B）
6. **紅線檢查**（過 / 沒過 + 原因）
7. **延伸潛力**（如果紅，可以延伸成什麼）

【輸出格式】
Markdown 表格 + 條列。直接可以貼進 04-topics/backlog.md。

【限制】
- 不要硬塞產品名（10 題裡產品介紹不超過 3 題）
- 不要重複 02-inventory/ 裡已經做爛的題型
- 任何踩紅線的題目，自己先砍掉再給
```
