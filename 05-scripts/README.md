# 短影音腳本草稿

## 命名規則

```
YYYY-MM-DD_<軸縮寫>_<題材關鍵字>.md
```

範例：
- `2026-04-28_成分_植萃精華使用順序.md`
- `2026-05-01_日常_換季敏感舒緩.md`

## 草稿前綴

未發布的草稿用 `draft-` 前綴：
```
draft-2026-04-28_成分_植萃精華使用順序.md
```

`.gitignore` 會自動排除 `draft-*`、不會推上 GitHub。

## 腳本格式

每份腳本用 `06-prompts/script-draft.md` 範本生成、含：
- 開頭 hook（3 秒抓住人）
- 主體（資訊 / 故事）
- 收尾 + CTA
- B-roll / 鏡位建議
- 字幕重點（3-5 句）
- 自查通過記錄（過了 `voice.md` 禁用詞檢查）
