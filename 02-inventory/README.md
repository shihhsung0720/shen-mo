# 過去內容盤點

## content-log.csv 欄位說明

| 欄位 | 意思 | 範例 |
|---|---|---|
| `post_id` | IG 貼文識別碼或自編號 | `2026-001` |
| `date` | 發布日期 | `2026-04-15` |
| `format` | 格式 | `Reels` / `照片` / `輪播` / `Story` |
| `title` | 標題或主視覺一句話 | `植萃精華怎麼用` |
| `main_axis` | 主軸 | `產品介紹` / `成分知識` / `日常保養` |
| `sub_topic` | 子題 | `精華液使用順序` |
| `product_mentioned` | 提到哪些產品（多個用 `;` 分隔） | `植萃精華;晚安霜` |
| `hook_type` | 開頭類型 | `提問` / `數字` / `對比` / `故事` |
| `cta` | 行動呼籲 | `下單連結` / `留言互動` / `無` |
| `likes` | 讚數 | `1234` |
| `comments` | 留言數 | `56` |
| `saves` | 收藏數 | `78` |
| `shares` | 分享數 | `12` |
| `reach` | 觸及人數 | `9876` |
| `notes` | 備註 | `系列第三集` |

## 規則

- **欄位順序不要改**、會破壞 Claude 解析
- 一筆一行、空欄留空、不要寫 `null` 或 `-`
- 主軸（`main_axis`）統一用 `03-axis-map/current-axes.md` 列出的名稱
- 互動數有就填、沒有就空、不要瞎估
