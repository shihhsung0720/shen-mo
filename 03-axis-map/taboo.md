# 不碰的題 Taboo

> 出題前先 Ctrl+F 一次。任何題目踩到下面任一條，**直接砍**。

## 法規類（會被罰錢的）

- 療效宣稱：治癒、根治、療效、抗 XX 病、改善 XX 病
- 醫療等級、藥用、藥妝（非合法分類者）
- 美白宣稱（除非用衛福部公告之美白成分且符合標示）
- 抗老宣稱（化妝品法規敏感）
- 減肥、瘦身（食品 / 化妝品）
- 「立刻」「100%」「永久」等絕對性用語
- 比較性誇大：「最強」「業界第一」（無第三方背書）

## 品牌避諱

- 政治：黨派、選舉、兩岸議題
- 宗教：任何宗教立場
- 競品：不點名、不比較、不影射
- 種族 / 性別 / 階級歧視
- 動物實驗（除非要主動表態反對立場，先確認再寫）

## 商業敏感

- 客戶個資（姓名、訂單、私訊截圖）
- 員工 / 合作夥伴未授權的人臉
- 內部成本、毛利、未公開行銷數字
- 通路 / 經銷商之間的價差或合約細節

## 暫時不碰（情勢敏感）

- （待填，例如某社會事件期間暫不發某類內容）

## 例外處理

如果某題你覺得「應該可以」但不確定：
1. 不要硬產
2. 在 `04-topics/backlog.md` 標 `[?]` + 寫疑慮
3. 等人工確認後再排程
